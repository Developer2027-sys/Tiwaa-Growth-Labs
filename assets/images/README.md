# Images

Put your brand images here. The site picks them up automatically. Keep the file names the same.

| File | Where it shows | Notes |
|---|---|---|
| `logo.png` | Navbar in **light** mode | Dark logo on a transparent background. About 440×197 px, shown 40 px tall |
| `logo-white.png` | Navbar in **dark** mode, plus the **footer** | White or light logo on a transparent background, same size |
| `favicon.png` *(optional)* | Browser tab icon, home-screen icon | Square, 512×512 px. If this file exists it is added to every page automatically |

The two logos currently in this folder were taken from the design artifact. Replace them with your final files.

After replacing images, run `npm run build` (or `npm run deploy`) so `public/` gets the new files.
